# TypeScript Replication Stream Client Example

This example decodes a `pkg/online/netplay` replication v2 stream (`SnapshotFull`, `SnapshotDelta`, and split `SnapshotFullPart`) and encodes `SnapshotAck` / `ResyncRequest` replies using the dependency-free TypeScript codecs generated by `game wire -lang ts`.

## Run the local demo

```sh
bun run examples/ts-replication-client/client.ts
```

## Run the tests

```sh
bun test examples/ts-replication-client
```

## Connect to a live `netplay.WebSocketServer`

```sh
bun run examples/ts-replication-client/client.ts --url ws://127.0.0.1:8080 --token my-token
```

## Regenerate the TypeScript wire codecs

```sh
go run ./cmd/game wire -lang ts -in pkg/online/netplay/wire -out pkg/online/netplay/wire/ts
```
