# Star Catcher — Asset Credits

Star Catcher draws its sprites and synthesizes its sounds in code (each chapter's `art.go` and `audio.go`), so the only asset file in the tutorial is the app icon, which `ch09-ship/tools/genicon` draws from `ch09-ship/internal/icon`.

| `ch09-ship/assets/Icon.png` | 1024×1024 app icon | NSGo Game Contributors (`ch09-ship/tools/genicon`) | [Apache-2.0](../../LICENSE) |

A game built from the tutorial that wants real art can start from the CC0 placeholder pack in `pkg/placeholder`.
