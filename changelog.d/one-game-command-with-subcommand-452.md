### Added

- `game` command, run as `go tool game`, with `pack`, `audio`, `manifest`, `tex` and `editor` subcommands that share `-in`/`-out` flags, usage and exit codes, and `game help` listing them; it replaces the separate `gamepack`, `gameaudio`, `gamemanifest`, `gametex` and `gameeditor` commands (#452).

### Removed

- The `gamepack`, `gameaudio`, `gamemanifest`, `gametex` and `gameeditor` commands, replaced by the subcommands of `game`. Calling a subcommand wrongly (a bad or missing flag, a stray argument, both `-peak-db` and `-rms-db`) now exits with 2 and prints its usage, where `gamepack`, `gamemanifest` and `gameaudio` exited with 1 for some of these; `tex` takes `-out` as well as `-o`. Generated manifests now start with `// Code generated by game manifest. DO NOT EDIT.`, so a checked-in manifest must be regenerated once before `game manifest -check` passes, and `game pack` and `game tex` record `game pack` and `nsgo game tex` as the writer in atlas JSON and KTX2 files (#452).
