### Added

- `game assets` builds every asset target in the new `assets` section of `game.yaml` in one run: it packs atlases, encodes KTX2 textures, converts audio and regenerates the asset manifest, and keeps a YAML cache of each target's settings, inputs and outputs so a second run with nothing changed writes no file and changing one image repacks only its atlas; `-check` lists out-of-date targets for CI, comparing with the committed outputs when the cache is absent (AAC and MP3 outputs, whose bytes depend on the encoder, only need to exist), and `-force` rebuilds everything. A renamed or removed target's old outputs are deleted, the cache key of an AAC or MP3 target names its encoder and version (`audioconv.Encoder.Tool`), and `game.yaml` refuses targets that would write over the project file or their own inputs. The `assets` section is part of package `project`'s one `game.yaml` schema (`project.Assets`), so `game release`, the editor and `game assets` accept the same file; `game/tooling/assetbuild` holds the builder, and `pack.ScanDir` lists the images `pack.PackDir` packs (#455).
