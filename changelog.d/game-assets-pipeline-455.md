### Added

- `game assets` builds every asset target in the new `assets` section of `game.yaml` in one run: it packs atlases, encodes KTX2 textures, converts audio and regenerates the asset manifest, and keeps a YAML cache of each target's settings, inputs and outputs so a second run with nothing changed writes no file and changing one image repacks only its atlas; `-check` lists out-of-date targets for CI, comparing with the committed outputs when the cache is absent, and `-force` rebuilds everything. The `assets` section is part of package `project`'s one `game.yaml` schema (`project.Assets`), so `game release`, the editor and `game assets` accept the same file; `game/tooling/assetbuild` holds the builder, and `pack.ScanDir` lists the images `pack.PackDir` packs (#455).
