### Added

- `examples/fieldmedic`: Field Medic, a small runnable game that ships its own scene editor (`cmd/editor`) with an editor plugin built in: a `health` component its game and editor share, and a `health` plugin with a Ward panel whose Heal All is one undoable step, an inspector for the component and an Admit tool; `docs/*/editor.md` describes how a game lays out and ships an editor with plugins (#492).
