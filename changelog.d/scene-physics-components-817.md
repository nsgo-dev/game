### Added

- `game/physics3d`, `game/resource`: add `physics3d.PhysicsMaterial` (`Friction`, `Restitution`, `LinearDamping`, `AngularDamping`) on `physics3d.Body` (`Body.Material`, `Body.ApplyMaterial`), honored in contact impulse solving and damping, plus `resource.PhysicsMaterial.ApplyTo3D` and `resource.Library.PhysicsMaterial` (#817).
- `game/project`: add the optional `physics` section to `game.yaml` (`gravity2D`, `gravity3D`, `solverIterations2D`, `solverIterations3D`, and named collision `layers` mapped to bits `0..31`) with validation, `game.v1.json` schema updates, and runtime helpers `PhysicsLayerTable`, `PhysicsSettings`, `ConfigurePhysicsWorld`, `ConfigureRigidWorld`, and `ConfigurePhysics3DWorld` (#817).
- `game/sceneformat`: add versioned built-in 2D and 3D physics components (`body2d`, `collider2d`, `trigger2d`, `body3d`, `collider3d`, `trigger3d`), `FieldStringList` and `Field.Enum`, named collision layer validation with exact file/line `*loaderr.Error` reporting via `ParseOptions.PhysicsLayers`, and `BuildPhysics` / `PhysicsScene` to instantiate and step `physics.World`, `physics.RigidWorld`, and `physics3d.World` directly from scene files (#817).
- `game/editor`: add automatic Play-mode physics simulation (`PlayPhysics`, `PlayTriggerEvents`, `OnPlayTrigger`), 2D and 3D viewport collider/trigger debug outlines (`ShowPhysicsDebug`), built-in physics component inspector editing (enum selectors and string lists), named layer validation on project/scene open, and the Project Settings Physics tab (#817).
