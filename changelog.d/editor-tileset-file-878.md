### Added

- `game/tilemap`: `TilesetDoc` (`*.tileset.yaml`, version 1) tiles now support optional `name` and non-negative `weight` (populated into `Tileset.TileProbabilities` and reflected in `tileset.v1.json`), and `*Tilemap` directly implements `physics.TileGrid` and `physics.TileGridOrigin` so tiles marked `solid` or `oneWay` collide through `physics.MoveAndSlide` with no Go code naming the tile (#878).
- `game/sceneformat` and `game check`: version 2+ single-grid inline tilemaps may reference `tilesetFile` in place of a `tileset` atlas (`data` + `tilesetFile`), building into `BuiltLayer.Map` with all tileset flags, collision shapes, animations and custom properties, and `tooling/assetcheck` reports missing `tilesetFile` references and out-of-range tile IDs with file and line (#878).
- `game/editor` and `game/editor/editormcp`: the Tileset Editor adds tabbed Collision (solid, one-way, custom flag bits, and interactive rect/polygon shapes drawn over the tile), Animation (frames, durations and live preview), and Custom Data (name, variant weight and typed properties) editing alongside Terrain, all undoable and reflected live in the 2D viewport (including live animated tiles in edit mode) and Play mode; a right-side Tile Inspector edits the active tile's collision and rules when painting, and MCP tools `tileset_read` and `tileset_edit` read and edit the same tileset fields (#878).
