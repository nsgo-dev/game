### Security

- `game/editor`: keeping a background task's review, dismissing a task that is Ready to review, and answering a task's permission prompt are now refused when an agent asks for them, so they stay the person's decisions. `Editor.KeepTask` and `Editor.ResolveTaskPermission` return the new `ErrTaskDecisionYouOnly` to an agent, `Editor.DismissTasks` skips Ready to review tasks for an agent, `Editor.StopTask` refuses a task that is Ready to review (stopping it would end its review without reverting its edits), and the `tasks_control` MCP tool refuses `keep`, `allow` and `deny`, `revert` and `stop` of a task bound to another session, and `stop` or `dismiss` of a Ready to review task. Agents and scripts that kept tasks or answered prompts through `tasks_control` must leave those steps to the person in the editor; review any task an agent kept in an earlier version (GHSA-264m-q5vc-h23x).
