### Security

- `game/editor`: files that look like credentials or the editor's private state (`.env`, `.env.*` and `*.env`, `.envrc`, `*.pem`, `*.key`, `*.p8`, `*.p12`, `*.pfx`, `*.jks`, `*.keystore`, `keystore.properties`, `.netrc`, `.npmrc`, `.git-credentials`, `credentials.json`, `google-services.json`, `GoogleService-Info.plist`, `service-account*.json`, `id_*` SSH keys, and anything under `.git/`, `.nsgo/`, `.aws/` or `.ssh/`) are now always refused to agents by `scene_read`, `refs_find`, `file_edit`, `refactor_rename`, the review, tileset, state machine, cutscene and playtest tools and the built-in agent, whatever the Usage and privacy switches say, including through in-project symbolic links, case-changed names and other spellings a case-insensitive file system opens as the same file; the `@`-mention picker no longer lists them and file chips never carry them. Previously such files were classed as scene and data files, which leave the computer by default. Update the editor, and rotate any credential an agent may already have read from the project (GHSA-769j-vg2v-mgv9).
