### Added

- `game size` checks a built package, a WebAssembly binary or an Android AAB or APK or iOS IPA, against its size budget, with the flags, reports and default budgets of the former `cmd/sizecheck`; run it as `go tool game size`. The measurements and budget checks behind it are the library package `github.com/nsgo-dev/game/pkg/tooling/sizecheck` (`sizecheck.LoadBudget`, `sizecheck.CheckMobilePackage`, `sizecheck.MeasureWasm` and so on).
- `game project` checks, formats and applies a project's `game.yaml` with the verbs of the former `cmd/gameproject`: `game project check`, `game project fmt`, `game project sync` and `game project targets`, each taking the project directory, the working directory by default. `-check` goes before the verb, as in `game project -check fmt`, and is only for `fmt` and `sync`.

### Changed

- `tooling/apiref`, the Go doc parser behind `tools/gameapi`, moves to `internal/apiref` and is no longer a public package: `github.com/nsgo-dev/game/pkg/tooling/apiref` can no longer be imported from outside this repository, and the package leaves the stability table and the API reference. The File Formats page's entry for `api.json` is now `internal/apiref`.
- The QR code encoder the editor's Web build card draws moves from `internal/qrcode` to `pkg/editor/internal/qrcode`, and the generator of the placeholder pack's sample glTF models moves from `internal/samplegltf` to `pkg/placeholder/internal/samplegltf`, next to their only users; run `go tool nsgo test ./pkg/placeholder/internal/samplegltf -update` to regenerate the models.
- `debug` moves from `pkg/debug` to `pkg/tooling/gamedebug` and is renamed `gamedebug`, so it no longer shadows the standard library's `runtime/debug`: import `github.com/nsgo-dev/game/pkg/tooling/gamedebug` and write `gamedebug.New`, `gamedebug.Console` and so on. Its errors start with `gamedebug:` instead of `debug:`, its File Formats entries are now `tooling/gamedebug` and `tooling/gamedebug#trace`, and the console saves tunables under the storage key `gamedebug.console.tunables` instead of `debug.console.tunables`, so tunables a game saved under the old key are not loaded. The guide moves to `gamedebug.md`.
- `online/accounts/token` is renamed `authtoken` and moves to `github.com/nsgo-dev/game/pkg/online/accounts/authtoken`, so it no longer shadows the standard library's `go/token`: write `authtoken.NewVerifier`, `authtoken.ParseKeySet` and so on where code wrote `token.NewVerifier`. Its errors start with `authtoken:` instead of `token:`, and its File Formats entry is now `online/accounts/authtoken`.
- `refs` moves from `pkg/refs` to `pkg/tooling/refs` and `playtest` from `pkg/playtest` to `pkg/tooling/playtest`, beside the other packages no release build links; their names are unchanged, so only the imports change: `github.com/nsgo-dev/game/pkg/tooling/refs` and `github.com/nsgo-dev/game/pkg/tooling/playtest`. Their File Formats entries are now `tooling/refs`, `tooling/playtest` and `tooling/playtest#report`.
- `tooling/pack`, the atlas packer behind `game pack` and `game assets`, is renamed `atlaspack` so it no longer reads as the asset packs of `tooling/library` and `placeholder`: import `github.com/nsgo-dev/game/pkg/tooling/atlaspack` and write `atlaspack.PackImages`, `atlaspack.PackDir` and so on. Its errors start with `atlaspack:` instead of `pack:`. The `game pack` command keeps its name.
- Package size checks exit with 1, not 2, when the budget file, the package or its ZIP archive cannot be read, as every `game` command does for a failure; 2 is left for a wrong call. Their errors start with `game size:` instead of `sizecheck:`, and the File Formats entries of the size budgets are now `tooling/sizecheck` and `tooling/sizecheck#mobile`.
- Project file checks exit with 2, not 1, when they are called wrongly, such as with an unknown verb, more than one directory or `-check` where it does not apply, and print the usage of `game project`; their errors start with `game project:` instead of `gameproject:`.
- `vehicle` is renamed `vehicle3d` so its name says it is the 3D raycast car on `physics3d`, as `physics3d` and `world3d` do: import `github.com/nsgo-dev/game/pkg/vehicle3d` and write `vehicle3d.New`, `vehicle3d.Config`, `vehicle3d.Race` and so on. Its errors start with `vehicle3d:` instead of `vehicle:`, and its File Formats entries are now `vehicle3d` and `vehicle3d#ghost`. Car files, ghost laps and snapshot checksums are unchanged. The guide moves to `vehicle3d.md`.
- `effects` is renamed `postfx` so its name says it is the full-frame shader passes drawn over the game's frame, apart from the per-sprite `Sprite.Effect` and the sound mixer's DSP effects: import `github.com/nsgo-dev/game/pkg/postfx` and write `postfx.Compile`, `postfx.View`, `postfx.Bloom` and so on. Its errors and panics start with `postfx:` instead of `effects:`. The guide moves to `postfx.md`.
- `online/server` is renamed `gameserver` and moves to `github.com/nsgo-dev/game/pkg/online/gameserver`, so its name says what it serves instead of colliding with every variable called `server`: write `gameserver.Runner`, `gameserver.NewMatchmaker`, `gameserver.NewRooms` and so on where code wrote `server.Runner`. Its errors start with `gameserver:` instead of `server:`, and the guide moves to `gameserver.md`.

### Removed

- `cmd/sizecheck` is gone: run `go tool game size` with the same flags instead of `go run github.com/nsgo-dev/game/cmd/sizecheck`.
- `cmd/gameproject` is gone: run `go tool game project`, with `-check` before the verb (`game project -check sync`), instead of `go run github.com/nsgo-dev/game/cmd/gameproject`. The project templates' READMEs and comments name `go run github.com/nsgo-dev/game/cmd/game project`.
