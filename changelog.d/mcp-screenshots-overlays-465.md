### Added

- `game/mcp`: `game_screenshot` tool captures the game view as PNG (written to a relative `.png` path inside `Config.ScreenshotDir`, or returned as `png_base64` text) with optional pixel-aligned overlays for sprite bounds (`bounds`), 2D physics collision shapes (`collision_shapes` / `physics`, covering `physics.World` boxes, circles, triggers, solid/one-way tiles and `physics.RigidWorld` bodies), world-space reference grid (`grid`, `grid_step`), camera frame (`camera`) and bitmap labels (`labels`), aligned across `tilemap.Camera` pan/zoom/parallax and the same `screen.Viewport`, `ViewportFunc` and view size `game_input_pointer` uses, including `CaptureFrame` images at a HiDPI pixel ratio. Frames the software rasterizer draws report what it left out in `skipped_ops` and `skipped_images` (#465).
