### Added

- `game/editor`: the editor switches between a project's scenes without a restart: the file browser opens a scene (`OpenScene`, its Open button or a double press), and the toolbar's File menu makes a new minimal scene under the project (`NewScene`), saves the scene under another path (`SaveSceneAs`) and reverts it to its file as an undoable step (`RevertScene`). `SceneDirty` and `HasUnsavedChanges` report unsaved edits by comparing encodings, so undoing back to the saved state clears them; the toolbar shows the scene's path with a marker while edits are unsaved and the window title follows (`SceneLabel`, `WindowTitle`); Mod+S saves (`Save`); and opening another scene (from the file browser, the Problems panel or a search or reference result), New Scene, quitting and closing the window ask to save, discard or cancel first. New errors: `ErrNoSceneFile` (Save or Revert without a file to write to or read) and `ErrFileExists` (NewScene or SaveSceneAs over an existing file) (#866).

### Changed

- `game/editor`: `EditorView` now sets the window title, to the open scene's path, a `*` while edits are unsaved and the editor's name, so a title an app set before calling it is replaced; an editor built on the package names itself with the new `Editor.AppName` field (default "NSGo Scene Editor"), as Field Medic's editor now does (#866).
- `game/editor`: `OpenFile`, `SaveFile` and `OpenProject` now set `Editor.ScenePath` when the scene's file lies in the open project and clear it otherwise, where before an app set it after `OpenFile`; `OpenScene`, `SaveSceneAs`, `OpenProblem`, `OpenSearchResult` and `OpenReference` clear `OnSave`, which persisted the scene open before; and the toolbar's Save leaves an unedited scene file as written instead of rewriting it (#866).
