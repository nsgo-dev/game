### Added

- `game/navbake3d`: bake 3D navigation meshes from level geometry, as Recast does: glTF models, scene files, `world3d` heightmaps and `GridMap`s and `physics3d` static colliders (voxel colliders included), selected by layer mask, are rasterized into a heightfield, filtered by slope, step height and clearance, eroded by the agent's radius, split into regions, traced into simplified outlines and built into convex polygons with height detail, one mesh per named agent type (radius, height, max slope, max climb). The meshes are saved in a versioned `*.navmesh.yaml` file a scene names in its new `navMesh` field, written byte for byte the same for the same level on every CPU architecture, with a JSON schema at `https://game.nsgo.dev/schemas/navmesh.v1.json`, and `Mesh.NavMesh` returns the `world3d.NavMesh` that finds paths, with `DrawDebug` to show it (#823).
- `game navmesh` bakes a scene's glTF level geometry for every agent type in `game.yaml`'s new `navigation` section and writes the file the scene's `navMesh` names (#823).
