### Changed

- `game/anim3d`: blend-space samples now loop only when their `Clip.Loop` is true; a sample whose clip leaves `Loop` false, the zero value, plays once and holds its last frame, so set `Loop: true` on locomotion clips that used to cycle (#546).
- `game/assets`: a `DLCManager` without a `PublicKey` refuses packs with `ErrInvalidSignature` unless `DLCOptions.AllowUnsigned` is set, and `LoadingView` documents that it notifies once per mount (#546).
- `game/modding`: `Reload` validates the updated manifest before unloading, so a broken `mod.yaml` leaves the loaded version running, and mods on the web fail with `ErrWebUnisolated` unless `ManagerOptions.WebUnisolated` opts in to running them with the page's authority (#546).

### Fixed

- `game/anim3d`: a root-motion step that crosses a loop boundary composes its rotations in playback order, so pitch-and-yaw clips no longer turn the wrong way at the wrap (#546).
- `game/anim3d`: layers that play a clip leave joints the clip has no track for untouched (override layers no longer reset them, additive layers no longer apply the negated reference), blend spaces honour `Clip.Loop` and share weight between samples at the same parameter, the step that completes a crossfade fires the outgoing state's events, `Update(0)` no longer starts transitions, a blend space shared by both crossfade states advances once per step, negative speeds fire events in reverse order, and two-bone IK aims a chain with one zero-length bone (#546).
- `game/physics3d`: rotated boxes collide, raycast and draw as oriented boxes instead of their AABB, contact impulses apply torque (spheres roll, boxes tip), sleeping bodies wake for kinematic, jointed and lost-support motion, fast bodies are swept against static geometry without being held back by contacts they already have, such as the floor they slide along, deep box-capsule contacts separate the whole capsule, coincident capsule contacts get perpendicular normals, deep triangle-mesh BVHs no longer drop triangles, non-finite body inputs fall back to defaults, massless kinematic bodies stay kinematic, duplicate mesh/heightfield IDs are reassigned and removed bodies drop their warm-start cache (#546).
- `game/scene3d`/`game/world3d`: `MeshCollider` caches its bounds, query visibility filtering is memoized so deep hierarchies no longer cost O(hits x depth), `Heightmap.Raycast` no longer scans the whole grid per ray, `FoliageLayer.BoundingRadius` keeps large instances visible while any part is in range, a zero `ChunkStreamer` no longer panics, `MeshLibrary.Add` returns 0 instead of looping when IDs run out, exhausted BVH leaf slots are retired instead of wrapping their generation, and the floating-origin, GridMap raycast and BVH sync docs match the code (#546).
- `game/math3d`: spline `DistanceToT` keeps float64 arc lengths and an interval-relative Newton tolerance so long curves stay precise, `ToEuler`/`ToEulerXYZ` keep roll near the gimbal pole, and ray-plane and ray-triangle tests use relative parallel thresholds (#546).
- `game/gltf`: loading refuses indices past the vertex count, attribute and morph-target count mismatches, mesh weights that do not match the targets, non-finite vertex data, `JOINTS_0` values past the skin, unordered sparse indices, a second GLB JSON chunk or misplaced BIN chunk, and an unsupported `asset.minVersion`; a sheared node matrix sets `Node.MatrixNotTRS` and keeps its translation (#546).
- `game/entities`: `entities.Set` with a `Transform2D` marks the hierarchy subtree dirty like `SetLocal`, `Each*` document when component pointers stop being valid, and the 2D hierarchy (transforms, visibility, keep-world reparenting, remove policies, snapshots) is documented (#546).
- `game/save`: `Delete` removes the backup before the primary so an interrupted delete cannot resurrect the slot, `Load` rewrites a missing or unparseable primary from the recovered backup but never one that only failed to read or that a newer build may have written, envelopes with unknown or duplicate fields are corrupt unless their version is newer (then `ErrFutureVersion`), directory-sync failures are returned except where the file system cannot sync a directory, stale `.save-*.tmp` files are swept, and migration idempotency is documented (#546).
- `game/assets`: a DLC pack is verified on the same reader it is mounted from and `DirPackCache` serves a mounted pack through one open file, so replacing the cache file cannot inject unverified bytes; pack entry and size caps are configurable through `DLCOptions.Limits` (#546).
- `game/render3d`: `ProjectSegmentNO`, `DebugDraw.DepthNO` and `Gizmo.DepthNO` clip debug lines and gizmos at the near plane of an OpenGL-style `[-1, 1]` projection, which the `[0, 1]` default hid the near half of, `Gizmo.AppendSegments` reuses a slice and `DrawGizmo` no longer allocates, planar translate handles are drawn as the squares picking tests, draws whose sort keys tie keep submission order, and occlusion culling is documented (#546).
- `game/physics3d`: `HingeJoint.Angle` is tracked across steps so hinges turn past ±π and limits can span more than a turn, box inertia uses the analytic (2/9)·m·Σe² mean and offset shapes add the parallel-axis term, rays that start inside a sphere or capsule report a normal facing the ray like boxes do, `CharacterController.PushForce` lets the character push dynamic bodies, and the docs describe slack `DistanceJoint` ranges and how to make dynamic bodies collide with the character (#546).
- `game/math3d`: frustum tests allow rounding slack relative to each plane so points on a distant far plane are not culled, `NewHermiteSpline3D` fills missing tangents with Catmull-Rom tangents instead of zero, uniform Catmull-Rom splines keep evenly spaced knots at coincident points, and curves are documented (#546).
