# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

## [0.2.0] - 2026-11-27

### Added

- `cmd/game`: add `-resources` to `game assets` and `game manifest` to write built asset outputs into `resources/` and emit `"asset:"` URIs without `//go:embed` (#1480).
- `pkg/sceneformat`: added `ComponentRegistry.Merge` (all-or-nothing merge with collision diagnostics naming both sides), `ComponentTypeSchema`, `ComponentRegistry.JSONSchema`, and `SceneSchema` for deterministic draft-07 scene component schemas (#1271).
- `pkg/jsonschema`: added `Schema.Default` to emit the JSON Schema `default` keyword (#1271).
- `pkg/editor/editorcmd` and `cmd/game`: added `editorcmd -schema` and `game schema [-out file] [project-dir | game.yaml]` to emit a project's deterministic scene JSON Schema without opening a window (#1271).
- `game/sceneformat`: `ComponentType.Spawn`, `SpawnOptions`, and `SpawnEntitiesWith` turn YAML scene components into typed ECS components in `entities.World`, resolving registered defaults up front, running in deterministic depth-first and sorted component-name order, and rolling back created entities on error (#1282).
- `docs`: add an English and Chinese [Accessibility Guide](docs/en/accessibility-guide.md) mapping the Game Accessibility Guidelines (GAG) and Xbox Accessibility Guidelines (XAG) to engine features, with end-to-end settings wiring, a pre-release checklist, and an Apple App Store Accessibility Nutrition Labels table (#1784).
- `game/editor`: Command Palette (`⌘K`) now searches open-scene nodes (`@` scope, selecting and framing on pick), Settings pages, recent items (`PaletteRecent`), command/file scopes (`>` / `#`), and natural-language "Ask the agent" prompts.
- `game/editor`: Scene Tree left rail adds a quick filter (`SceneTreeFilter` / `SetSceneTreeFilterOpen`) and a quick-add `+` menu (`AddSceneRailObject`, `AddSceneRailLayer`) for creating undoable empty objects, triggers, lights, and layers.
- `game/editor`: 2D edit viewport draws the Spec 16×16 neutral dot-grid surround (`ViewportDot`) and neutral markers for visible non-sprite objects, and updates the `Camera · W × H` caption reactively on canvas layout changes (`SubscribeCanvasSize`).
- `game/input`, `game/project`, `game/save`, `game/a11y`, `game/gameui`: added fixed-step player motor assists (`input.Assists` with `Toggle`, `MashToHold`, `MinPress`, and `AcceptDelay`) on `Actions` and per `Player` with `SetPaused` / `ReleaseToggles`, `game.yaml` action `assist: {toggle, mash, mashRate}` declarations (`project.ActionAssist`), persistence in `save.Settings.InputAssists` and `a11y.Assist` (`ApplyToActions` expanding `HoldToToggle` from declared toggleable actions), replay determinism, and Controls tab rows in `gameui.SettingsMenu` (#1777).
- `game/sound`, `game/save`, `game/gameui`: add mono voice panning (`Mixer.SetMono`, `Mixer.Mono`, `Mixer.FollowSystemMono`) and left/right stereo balance (`Mixer.SetBalance`, `Mixer.Balance`) backed by `save.AudioSettings.Mono` (follow-system by default) and `save.AudioSettings.Balance` plus Audio tab rows in `gameui.SettingsMenu` (#1781).
- `game/physics`: add `MoveAndSlideInto`, `World.MoveAndSlideInto`, `World.MoveAndSlideWithInto`, `CharacterBody.MoveInto`, and `CharacterBody.MoveWorldInto` to reuse contact and collision slices across fixed steps (#1660).
- `pkg/sound`: added `Music.PlayLooped(src, loopStart, fade)` using NSGo's native `audio.PlayerOptions.LoopStart` for single-file intro-and-loop music without a two-player handoff seam, and documented intro-and-loop playback in `docs/en/sound.md` and `docs/zh/sound.md` (#1497).
- `pkg/gameui`: `ImageProgress`, a read-only progress meter built from under/progress/over `NineSlice` image layers, with linear fills (`left_to_right`, `right_to_left`, `top_to_bottom`, `bottom_to_top`, `center_h`, `center_v`) and radial pie fills (`clockwise`, `counter_clockwise` with `StartAngle` and `Span`) that keep nine-slice caps at any value; the `image_progress` screen node maps `under`/`progress`/`over`/`fill`/`startAngle`/`span`/`min`/`max`/`value` onto it, and `game check`, `refs`, and `game mv` follow the new image fields (#1427).
- `pkg/online/liveops`: add local re-engagement reminders (`Reminders`, `RemindersConfig`, `QuietHours`, `ParseReminders`, `LoadRemindersFS`, `EncodeReminders`) over NSGo's `core.Scope.ShowNotification`, with versioned YAML definitions and JSON Schema (`reminders.v1.json`), lazy notification permission on first `Schedule` or explicit `RequestPermission`, persisted player toggle and quiet hours, foreground cancel/reschedule/keep reconciliation, and `CanScheduleNotifications` reporting (#1310).
- `pkg/online/liveops`: added `ReviewPrompt` over `core.Storage` and `core.Scope.RequestReview` to gate in-app store rating requests on minimum sessions, days since first launch, positive moments, cross-version cooldown, once-per-version limits, negative-moment suppression, and fail-closed versioned JSON state (#1767).
- `pkg/online/liveops`: add `Invites`, `ShareHost`, `PlatformShareHost` (mobile, desktop and web), `MiniGameShareHost`, canonical signed/bounded `key=value&…` invite payload helpers, and 5:4 frame snapshot helpers for share cards (#1738).
- `pkg/modding`: added `mod.yaml` version 2 (`ManifestVersion = 2`, `MinManifestVersion = 1`) with `optionalDependencies`, `conflicts` (`ErrConflictingMods`), `platforms` (`ErrUnsupportedPlatform`, `SupportedPlatforms`, `ManagerOptions.Platform`), and `contributes` (`ModContributes` with `assets`, `scenes`, `l10n`, and `datatables`), including content-only v2 mods without an `entry` script and published `mod.v1.json` / `mod.v2.json` JSON Schemas (#1285).
- `pkg/modding`: added `Manager.ContentFS()` read-only content overlay in load order (later mods win per path) with strict mod-directory path and symlink confinement (`ErrUnsafePath`), plus a content-only sample mod under `pkg/modding/testdata/mods/slime-pack` (#1285).
- `game/pkg/modding`: hosts can register custom TSX modules (`ModModule`, `ManagerOptions.Modules`, `RegisterModule`) gated by dotted host capabilities (`HostCapability`, `ManagerOptions.Capabilities`), resolve the calling mod with `Caller`, enforce per-call checks with `ModAPI.RequireHost`, narrow grants with `ManagerOptions.GrantHost` and `Manager.SetHostGrant`, emit TypeScript declarations with `WriteModAPIDTS`, and declare dotted host capability names in `mod.yaml` (`ModManifest.HostCapabilities`, `mod.v1.json`) (#1284).
- `docs`: a Mods, plugins and packs section in `docs/en` and `docs/zh` compares editor (Go) plugins, script mods and library packs — what each is written in, who writes it, when it loads, its trust and platform rules, and whether it extends the editor — and links the editor, modding and library pages to each other, with matching rows in the from-Godot and from-Unity maps (#1268).
- `game/online/netplay`: `Auth.StaticKey` and `UDPServer.PublicKey` configure and expose a UDP server's static X25519 key for the Noise NK handshake, `UDPTransport.AddPeerKey` adds optional per-peer pre-shared-key ChaCha20-Poly1305 AEAD framing, and `ErrInvalidKey` and `ErrSequenceExhausted` report invalid keys and exhausted 32-bit sequence counters (#1299).
- `netplay`: `WebSocketServer.Kick(peer, reason)` and `UDPServer.Kick(peer, reason)` end one peer's session for good; `PeerEvent.Reason` carries the reason, and the client learns it as a `*KickError` (matching `ErrKicked`) from `Err` — over a WebSocket close frame with code 4001, over an encrypted kick datagram on UDP, and in the browser too (#1313).

- `game/online/netplay`: WebTransport transport (`WebTransportServer`, `WebTransportTransport`, `ListenWebTransport`, `ListenWebTransportFiles`, `DialWebTransport`, `WebTransportSupported`, `DialWebTransportWithFallback`, `WebTransportOptions`, `ErrWebTransportUnavailable`) delivering `ChannelUnreliable` as independent QUIC datagrams without TCP head-of-line blocking and `ChannelReliableOrdered` over a bidirectional QUIC stream, with a browser `syscall/js` client, `RelayServer` support, certificate hash pinning for local development, and WebSocket fallback (#1300).

- `game/pkg/online/netplay/wire`, `game/cmd/gamewire`: TypeScript codec backend (`-lang ts`, `wire.GenerateTS`, `wire.GenerateTSRuntime`) generating deterministic, zero-dependency `encodeX`/`decodeX` and delta `diffX`/`applyX` codecs over caller-owned `Uint8Array`/`DataView` with `bigint` 64-bit integers and pure-`BigInt` `qfloat`/`fixed` quantization, shared cross-language YAML golden vectors under `pkg/online/netplay/wire/testdata/vectors/`, a Go `ServerWorld` to TypeScript end-to-end test, and a TypeScript replication stream client example under `examples/ts-replication-client/` (#1304).
- `game/cmd/nsgo-game`: add the `nsgo-game` extension binary entrypoint (`go install github.com/nsgo-dev/game/cmd/nsgo-game@latest`) so `nsgo game` works outside a Go module through NSGo's generic extension mechanism.

- `game/pkg/plugin/manifest`: add strict YAML parser (`Parse`, `ParseFS`), validator (`Validate`, `ValidateName`, `ValidateModulePath`, `ValidatePackagePath`), canonical byte-ordered encoder (`Encode`), and published JSON Schema (`plugin.v1.json`) for Go plugin `plugin.yaml` manifests (#1270).
- `pkg/random`: `Stream.Normal(mean, stddev)` draws from a normal distribution, and `Stream.InCircle(r)`, `Stream.OnCircle()` and `Stream.InRect(x, y, w, h)` return points uniformly distributed inside a circle, on the unit circle (a random direction) and inside a rectangle, all from the seeded stream with a fixed, architecture-independent algorithm so replays and lockstep match (#1366).
- `cmd/editor`: standalone desktop application entrypoint (`NSGo Game Editor`) packaged and signed automatically on releases across macOS (`arm64`/`x64` `.dmg`, Developer ID signed and notarized), Linux (`x64`/`arm64` `.deb`, `.pkg.tar.gz`, `.AppImage`), and Windows (`x64`/`arm64` `-setup.exe`), alongside signed update appcasts and `install.sh`/`install.ps1` scripts.

- `pkg/sceneformat`: added the built-in `on_screen` component, which emits `entered`/`exited` events (wireable through scene `connections`) when an object's rectangle enters or leaves every camera view, with a `margin` hysteresis band and a `pause` list that stops the object's particle emitter or skeletal rig updates while off-screen; `BuiltScene.Notifiers` holds the runtime states and `BuiltScene.UpdateWithViews` accepts extra views, such as every split-screen viewport's camera (#1369).

- `sceneformat`: the built-in `timer` component (`RegisterTimerComponent`, in the editor's inspector and the scene JSON schemas) emits `timeout` on the game clock through `Signals.Update`, with `seconds`, `oneShot` and `autostart` fields and `start` and `stop` handlers, so a scene wires a timer to any handler with no Go code (#1362).
- `game/online/audit`: an append-only JSON Lines audit log for dedicated servers — one `<yyyy-mm-dd>.jsonl` file per UTC day rolled at midnight, a bounded queue that drops and counts instead of blocking, batched fsyncs and day-based retention (#1329).
- `pkg/online/server`: `/metrics` gains per-match tick histograms (`Runner.Health` records every tick, or `Health.ObserveMatchTick` directly), per-match overrun and missed-tick counters (`Health.OnOverrun`), guard totals across every peer seen (`Guard.Totals` and `GuardCollector`), transport inbox drop and refusal counters (`InboxCollector`), and `Health.AddCollector` for a game's own series; an unnamed match is exported as `match_<index>` (#1331).
- `pkg/online/server`: a panic in one match's `Update` or `OnStop` is recovered and reported through `Runner.OnPanic`; the default `StopMatch` action ends only that match while sibling matches keep running, and `Crash` stops every match, runs every `OnStop`, then re-panics from `Run`. `Panic.Report` builds a crash report with the client's JSON schema (#1314).
- `pkg/online/liveops/crashreport`: new NSGo-free package holding the `CrashReport` and `StepRecord` JSON schema, kept as aliases in `pkg/online/liveops` so existing code is unchanged (#1314).
- `pkg/online/cloudsave`, `pkg/online/leaderboard/selfhost`: hand-written OpenAPI 3.1 descriptions (`openapi.yaml`), embedded and served unauthenticated at `GET /v1/openapi.yaml`, published under `https://game.nsgo.dev/schemas/`, and enforced against each service's HTTP handler by CI contract tests (#1303).
- `pkg/importsettings`, `pkg/tooling/pack`, `pkg/tooling/assetbuild`, `pkg/sprite`, `pkg/sceneformat`, `pkg/editor`: trace per-frame 2D convex collision polygons from sprite alpha and bake named image points (`muzzle`, `hand`, `feet`) into packed atlas metadata, read Aseprite slice pivots, add `Sprite.PointWorld` / `Sprite.ShapesWorld`, add `collider2d` / `trigger2d` `shape: sprite` following frame changes, flips, scale, and rotation, and overlay traced outlines and draggable points in the editor's image import inspector (#1758).
- `game assets`: a font target may bake a bitmap font from a folder of PNG glyph images, such as score digits or damage numbers, with `glyphs` mapping names that are not one character to their character, and `spacing` and `align` for the advance and line placement (#1348).
- `game/input`: `TouchControls` builds a layer of on-screen controls from a `TouchLayout`, a versioned YAML document (`ParseTouchLayout`, `EncodeTouchLayout`, schema `touchlayout.v1.json`): controls anchored in the safe area that scale with the screen and never shrink below 44 points, drive the same actions and axes as the keyboard and controllers, show on the first touch and hide on keyboard or controller use, start visible on coarse-pointer devices, fade when idle, mirror for left-handed play, tick through `Haptics` on press, carry accessibility labels as canvas nodes, and save a player's edited layout in `core.Storage`.
- `game/input`: `RegisterTouchControlKind` and `RegisterTouchIcon` let a plugin add control kinds and button icons a touch layout names; a kind implements `TouchControl`, a `VirtualControl` that `TouchControls` places, and optionally `ButtonControl`, so the pad treats a control built on a `VirtualButton` as one of its buttons, and `AccessibleControl`, to report its own accessibility role. `TouchControls.Wake` restores full opacity when the controls come back into view.
- `game/input`: `VirtualDPad`, a 4- or 8-way d-pad one finger owns and rocks between directions, driving actions and an optional up-positive axis pair; `VirtualPad.Controls`, `AddControl`, `SlideBetweenButtons` (a finger sliding onto another button presses it) and `OnPress`.
- `game/input`: `VirtualButton.Mode` (`ButtonHold`, `ButtonToggle`, `ButtonTap`), `VirtualButton.Icon` and `Held`, and `VirtualStick.UpPositive`, which reads pushing up as a positive `AxisY` like a game controller's inverted stick; the default stays screen-down positive.
- `game/tween`: `tween.Ease`, a named easing function covering the sine, quad, cubic, quart, quint, expo, circ, back, elastic, bounce and spring families, each in the in, out, in-out and out-in variants, sharing its names with the `interp` values of resource curve keys so clips and code use the same eases (#1411).
- `game/tween`: `To`, `By` and `FromCurrent` read the start value when the step runs, not when it is built, so steps compose from whatever an earlier step left behind; rewinding the timeline reads the start again (#1411).
- `game/tween`: `Sequence` builds a `Timeline` without computing start times by hand — `Then` appends steps, `With` runs a step in parallel with the last one, `Wait` inserts an interval, `Call` schedules a callback and `Loops` repeats the run — and `Timeline.SetLoops(n)` counts runs exactly on any timeline (#1411).
- `game/tween`: `Timeline.SetSpeed`, `Group.SetSpeed` and `Group.SetPaused` scale or freeze playback for slow motion and game pauses, `Group.AddTimeline` steps timelines alongside tweens, and `Group.Bind(cx)` clears the group when the scope ends (#1411).
- `game/undo`: `History` gains the three tools an in-game editor needs: `Limit` bounds how many moves are kept (the oldest applied moves are forgotten first), `DoMerge` and `EndMerge` fold the steps of one drag into a single move through the new `Merger` interface, and `MarkSaved`, `Dirty` and `Version` track the saved point for an "unsaved changes" mark (#1365).
- `website`: add mobile play mode to the playground on touch screens with native fullscreen and a `100dvh` overlay fallback, page scroll locking, per-example orientation metadata with a rotate-your-phone prompt, and touch hint copy across all locales (#1298).
- `online/wsclient`: a plain RFC 6455 WebSocket client for third-party servers (Nakama, Colyseus, chat integrations, custom protocols), with the same `Dial`/`Send`/`SendText`/`Recv`/`Close` API on native and web targets; see [wsclient](docs/en/wsclient.md) (#1448).
