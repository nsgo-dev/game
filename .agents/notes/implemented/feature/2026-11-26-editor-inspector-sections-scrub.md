# Agent Note: Editor inspector titled sections, field filter, scrub fields, Open YAML, and Ask to add

Status: implemented

## Problem

The object inspector from [editor-inspector-components-sprite](2026-11-25-editor-inspector-components-sprite.md) stacked flat fields without collapsible sections, field filtering, label-drag scrubbing, YAML line navigation, grouped component categories, or review/problem markers. Issue #1038 aligns the inspector with `docs/design/editor/Inspector.dc.html`, `Main.dc.html`, and `Viewport3D.dc.html` using Spec tokens while preserving every existing `Editor` method, `TestID`, and full `editormcp` parity.

## Decision

- **Single-undo-step live label scrubbing (`inspector_sections.go`, `inspector_scrub.go`)**: `BeginInspectorScrub`, `UpdateInspectorScrub`, `EndInspectorScrub`, and `CancelInspectorScrub` wrap normal `Editor` setters inside `History.beginPreview` / `endPreview` / `commitPreview`. Each live update rolls back the previous preview command before applying the new value so the preview group holds at most one command from the exact pre-scrub document state (preserving nil pointer fields like unset `ScaleX`), committing **one undo step** on release and restoring verbatim with zero history steps when cancelled (including via `Escape` during a scrub or before Save/Play/Undo). Unset registered component fields read their schema default as the scrub starting value rather than zero. In `ViewMode3D`, `Shift` scrubs non-integer fields in `0.01` increments; in `ViewMode2D` and keyboard `Shift+↑/↓`, `Shift` steps ×10.
- **Spec-styled titled sections and focus-preserving field filter (`inspector.go`, `inspector_edit.go`)**: `InspectorView` renders the Spec header with **Open YAML** (`FindObjectYAMLLine` / `OpenSelectedObjectYAML` using `yaml.v3` AST lookup over the clean disk file or dirty `SaveYAML`, invoking injectable `Editor.OnOpenFileAtLine`), object kind swatch and `"<Kind> · layer <layer>"` subtitle, and **Filter fields** (`InspectorFilter` / `SetInspectorFilter`) mounted outside the filtered `core.Dynamic` so typing never drops focus. Every object section (`TRANSFORM`, `SPRITE`, `PARTICLES`, `PROPERTIES`, `CONNECTIONS`) and every attached component (`PATROL`, `HEALTH`, `PHYSICS`, …) renders as a collapsible Spec titled section with field counts, compact X/Y (and Z in 3D) rows, optional `"was <old> · in review"` sub-rows (`SetInspectorReviewChanges`), and problem pills (`SetInspectorFieldProblems` / `Editor.Problems` / schema bounds checks), ending with the Spec footer and grouped **Add component** (`GAMEPLAY`, `PHYSICS`, `AUDIO AND VISUAL`) beside **Ask to add** (`AskToAddComponent`, `ComposerDraft`, `Editor.OnComposerPrompt`).
- **MCP parity (`editormcp/inspector.go`, `editormcp/edit.go`)**: Added `object_set_field` (delegating to `setObjectFields`, `setComponentFields`, and `SetProperty` inside `History.Group`) and `object_locate_yaml` (backed by `FindObjectYAMLLine` and optional `OnOpenFileAtLine`), and extended `scene_edit`'s `set` op with `particles`, `model`, `gridMap`, `occluder`, `light`, and `camera` so every inspector edit is available to agents without duplicating validation.

## Alternatives considered

- **Re-use `ui.NumberInput.LeadingText` built-in scrubbing directly**: `base.NumberInput` calls `OnChange` on every pan step and only exposes `OnChangeEnd`, without a begin/cancel lifecycle or 3D `Shift` 0.01 fine stepping, so dragging a transform field would push dozens of separate undo steps onto `Editor.History` and could not roll back cleanly on `Escape`. Wrapping `base.NumberInput` with a dedicated `inspectorScrubHandle` driving `BeginInspectorScrub`/`UpdateInspectorScrub`/`EndInspectorScrub`/`CancelInspectorScrub` keeps `base.NumberInput` untouched while guaranteeing one undo step and exact `Escape` rollback.
- **Expose only `scene_edit` without `object_set_field` or `object_locate_yaml`**: Keeps the tool list smaller, but forces agents to assemble batch edits to tweak one field and leaves non-selected objects without a direct YAML line lookup matching **Open YAML**. Adding two thin wrappers over the existing `editormcp` helpers gives clean one-to-one parity with zero duplicated validation.
- **Put `InspectorFilter` inside `inspectorSchemaKey`**: Would remount the entire object inspector on every keystroke, dropping input focus from `inspector-field-filter`. Keeping the filter input above a dedicated filtered `core.Dynamic` preserves focus while updating sections live.

## Consequences

- **Benefits**: Every existing inspector `TestID`, plugin inspector, connection editor, and locale contract stays intact; scrubbing is live, single-undo, and Escape-cancellable; agents and humans share identical validation and YAML line lookup.
- **Costs**: `Editor` carries six small inspector UI state fields (filter, collapse map, scrub session, composer draft, review changes, explicit field problems) and two new MCP tools (`object_set_field`, `object_locate_yaml`) that tool-list tests track.
- **Verification**: `packages/game/editor/inspector_sections_test.go` verifies header + Open YAML exact 1-based line, `"speed"` field filtering, X-label drag scrub (1 undo step + Escape cancel + 3D Shift 0.01 fine step + unset default start), grouped Add component + Ask to add composer draft, review/problem indicators, section collapse, and real macOS `nsgotest` screenshots; `packages/game/editor/editormcp/inspector_test.go` covers `object_set_field`, `object_locate_yaml`, and extended `scene_edit` fields.
