# Agent Note: game doctor JSON findings

Status: implemented

## Problem

Project checks were split between `nsgo doctor`, `game project`, and asset checks, making support reports incomplete.

## Decision

Add `game doctor [dir]` with stable findings containing `severity`, `file`, `message`, and `fix`. Human output is line-oriented and `-json` emits the same findings as an array. The first implementation covers module tool declarations, project parsing, default IDs, and export presets.

## Consequences

Agents can collect one machine-readable project report. Editor readiness integration, network resolution checks, signing and icon inspection remain follow-up work.

## Alternatives considered

A shell wrapper around existing commands was rejected because it could not provide one stable JSON contract or preserve findings from multiple checks.
