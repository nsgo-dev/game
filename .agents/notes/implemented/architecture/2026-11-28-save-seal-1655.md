# Agent Note: tamper-evident save envelopes

Status: implemented

## Problem

Save JSON remained editable without detection, and copies could be loaded under another account.

## Decision

`WithSeal(SealOptions)` adds a deterministic `hmac-sha256:` field over the version, data and caller-provided binding. The caller supplies the key through a function so platform keychain or server-derived secrets stay outside the save file. Mismatches return `ErrTampered` by default or invoke the report hook under `SealReport`.

## Consequences

Save files remain readable JSON while edits and cross-account copies are detected. Existing unsealed saves remain readable and can be sealed on their next write. Keychain integration and default per-install secret generation remain caller responsibilities.

## Alternatives considered

Encryption and obfuscation were rejected because saves must remain text and support backups and inspection. A package-generated key was rejected because it would not provide a platform-backed secret boundary.
