# Credits

Everything the game draws is built in code by this project's Go files, except the trackside crates, which come from the game layer's placeholder pack.

| Asset | Where it comes from | Author | License |
| --- | --- | --- | --- |
| Road, curbs, ground, checkpoint posts and cars | `meshes.go` and `scene.go`, built at startup | This project's authors | This project's license |
| `models/crate.glb`, the crates | `placeholder.Model` in `github.com/nsgo-dev/game/packages/game/placeholder` | NSGo Game contributors | CC0-1.0 |

The placeholder pack's own `CREDITS.md`, which `placeholder.FS` returns, lists every file in it. Credit is not required for CC0 works; a game that wants to give it can write "Placeholder art: NSGo Game contributors, CC0".
