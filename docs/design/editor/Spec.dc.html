Principles
AI first. The agent does the bulk editing through the editor's MCP server; people ask, watch, review and fine-tune. Every manual tool is also reachable by the agent.
Nothing lands unseen. Agent edits show in the viewport and tree as they happen, and each request becomes one review with per-change keep or revert, and one undo step.
Few tools, finished. Select, move, rotate, scale, pan, an inspector for fine values. A feature ships only when its empty, loading, error, focus and keyboard states are designed.
Text is the truth. Everything the editor shows is a YAML file the agent and git can read; the editor never holds state a file doesn't.
Ask before the irreversible. Running the game, touching Go code or deleting files asks first unless the person allowed it.
Acceptance for every editor PR
Real screenshots from nsgotest on macOS, before and after, beside the matching artboard.
Uses only the tokens on this board, and every text pair is in the contrast table.
Every control shows the focus ring and is reachable with Tab, F6 or arrows.
Every action has a shortcut row with a scope below, and an MCP tool.
Overlays follow the line-style legend; nothing is told apart by hue alone.
Reviewed by a person looking at the screenshots, not only by tests.

Controls and icons
Real elements. Actions are <button>, navigation is <a href>, fields are <input> with a <label>. Never a clickable div or span.
Toggles and choices. On/off is a button with role switch and aria-checked; Allow / Ask / Deny is a radio group moved with arrows; palette cells are a grid of buttons.
Names. Icon-only buttons carry aria-label; their tooltip shows the same name and the shortcut, e.g. “History · ⌘Y”.
Live regions. Agent status and toasts announce through aria-live polite; a permission card is an alertdialog that does not take focus by itself.
Icons. One inline stroke set, 1.8 px at 15 px, currentColor, aria-hidden. Never characters or emoji as icons.

F6next ·⇧F6previous
01
Text fields take every unmodified key. Single-letter shortcuts (V W E R F B J K X) fire only when focus is not in a text field. Shortcuts with ⌘ work everywhere unless the field uses them (⌘↵ sends in the composer).
02
Esc steps back, it never stops the agent. In order: leave the text field, cancel a transform in progress, clear the selection, close the popover or dialog. Stopping the agent is ⌘. from anywhere, or the Stop button.
03
⌘↵ says yes, ⌘⌫ says no, to what is in front of you. Composer: send. Permission card: allow once and deny. Review: keep and revert. With none of them focused, ⌘↵ keeps the open review; with no review open it does nothing.
04
Dialogs trap focus. Tab cycles inside, Esc cancels and focus returns to the control that opened it. Global shortcuts are off behind a dialog, except ⌘. to stop the agent.
05
The agent never steals focus. A new permission card or question is announced politely and shown in the header pill; it takes focus only if focus was already in the agent panel. Nothing moves focus during a drag or while typing.
06
Every viewport action has a keyboard path. Arrows nudge, typed numbers set rotation and scale exactly, Tab walks objects. Pointer-only gestures are shortcuts for something the keyboard can also do.
07
Rebinding checks the scope. Settings › Shortcuts flags a key already used in the same scope in place and offers Swap; the same key in different scopes is allowed.
ShortcutsmacOS keys. Windows and Linux swap ⌘ for Ctrl and keep the rest.
