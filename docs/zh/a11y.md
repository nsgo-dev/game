# a11y

`game/a11y` 基于 NSGo 公开 API 提供游戏无障碍基础组件：对话与方向性音效实时字幕、色盲友好调色板与色觉缺陷（CVD）模拟、持久化辅助选项，以及适配屏幕阅读器的原生菜单。

关于如何与 `gameui.SettingsMenu`、`effects`、`sound`、`input.TouchControls` 端到端串联，以及 Game Accessibility Guidelines / Xbox Accessibility Guidelines 对照表、发布前核查清单与 Apple App Store 无障碍营养标签说明，请阅读[无障碍指南](accessibility-guide.md)。

```go
import "github.com/nsgo-dev/game/pkg/a11y"
```

## 持久化辅助选项（`Assist`）

`NewAssistFromSettings(cx, store)` 将 `*Assist` 绑定到游戏共享的 `*save.DefaultSettingsStore`（`save.Settings.Accessibility`），使 `gameui.SettingsMenu`、`CaptionsView`、`AccessibleMenu` 与 `postfx.Flash` / `postfx.Shake` 在保存设置后自动保持同步。在 `save.SettingsTargets` 上配置 `ApplyAccessibility: assist.ApplySettings`，还可在点击 `SettingsMenu.Apply()` 时即时预览未保存的更改：

```go
store := save.NewStorageSettingsStore(cx.Storage(), "mygame")
assist := a11y.NewAssistFromSettings(cx, store)

// 在 game.Loop.Update 中按 GameSpeed（0.25..2.0）缩放模拟步长 dt：
loop := &game.Loop{
	Update: func(dt time.Duration) {
		sim.Step(assist.ScaleDT(dt))
	},
}
```

已弃用的 `NewAssist(cx, key)` 遗留在 `cx.Storage()` 中的旧版 `"a11y.assist.*"` 键会在启动时一次性迁移到 `store` 并删除；若旧版使用了自定义前缀，可调用 `MigrateLegacyAssist(cx.Storage(), oldPrefix, store)`。`ParseColorVision` 同时接受 `"normal"` 与 `"none"` 表示 `VisionNormal`。

`*Assist` 支持的持久化选项（亦可通过 `Snapshot()`、`Apply(opts)` 与 `Reset()` 整体读写 `AssistOptions`）：

| 选项 | 范围 / 默认值 | 说明 |
| --- | --- | --- |
| `GameSpeed` / `ScaleDT` | `0.25`–`2.0`（`1.0`） | 缩放游戏逻辑 `dt`，不影响显示刷新率。 |
| `ReduceMotion` | `bool` | 未设置时默认读取 `cx.Env().ReduceMotion()`；显式调用 `SetReduceMotion(false)` 可覆盖系统设置。 |
| `ReduceFlashes` | `bool` | 独立于 `ReduceMotion` 关闭全屏闪烁效果。 |
| `ScreenShake` | `0.0`–`1.0`（`1.0`） | 屏幕震动强度倍率（`0` 表示关闭震动）。 |
| `HighContrast` | `bool` | 未设置时默认读取 `cx.Env().IncreaseContrast()`；开启后 `assist.Palette()` 返回 `VisionHighContrast`。 |
| `ColorVision` | `ColorVision` | 选择 `VisionNormal`、`VisionProtanopia`、`VisionDeuteranopia`、`VisionTritanopia` 或 `VisionHighContrast`。 |
| `TextScale` | `0.5`–`3.0`（`1.0`） | 未设置时默认读取 `cx.Env().FontScale()`（经范围裁剪）；`CaptionsView` 与 `AccessibleMenu` 自动应用。 |
| `Invincibility`、`AutoAim` | `bool` | 供战斗层读取的辅助开关。 |
| `HoldToToggle` | `bool` | 快捷开关：通过 `ApplyToActions` / `ApplyToPlayers` 应用时，自动把 `input.Actions` 上声明可切换的动作填入 `input.Assists.Toggle`。 |
| `InputAssists` | `input.Assists` | 持久化在 `save.Settings.InputAssists` 中的按动作 `Toggle`、`MashToHold` 列表及 `MinPress`（慢速键）、`AcceptDelay`（防抖键）。 |
| `CaptionsEnabled`、`SFXCaptionsEnabled` | `bool` | 分别控制对话字幕与音效字幕开关。 |

启用 `AutoAim` 后，在固定步更新中使用 `input.AimAssist`。它提供确定性的 2D 和 3D 减速、磁吸、可选吸附、目标优先级以及由游戏提供的可见性回调。`Strength` 是玩家可调强度，0 表示关闭，1 表示完整效果。

`Assist.Reset()` 仅重置 `save.Settings.Accessibility` 与 `save.Settings.InputAssists` 并恢复跟随系统偏好，不会清除共享存储中的音频、显示、键位、语言与自定义字段。

## 玩家运动辅助

`Assist` 将 `input.Assists` 持久化到 `save.Settings.InputAssists`，并通过 `ApplyToActions` / `ApplyToPlayers` 将 `InputAssists` 与 `HoldToToggle` 同步到 `input.Actions`（或 `input.Players`）。在 `save.SettingsTargets` 上同时配置 `ApplyAccessibility: assist.ApplySettings` 与 `ApplyInputAssists: assist.ApplyInputAssists`，即可让 `gameui.SettingsMenu` 的控制标签页即时预览并保存运动辅助：

```go
cx.Effect(func() {
	assist.ApplyToActions(actions)
})
```

开启 `HoldToToggle()` 时，`ApplyToActions` 会自动将 `actions.ToggleableActions()`（来自 `game.yaml` 中的 `assist: {toggle: true}` 或 `SetActionAssist`）合并到 `input.Assists.Toggle`，使游戏内长按动作转为切换，同时永不锁存菜单动作。固定步长求值、暂停释放与回放确定性详见 [input](input.md#玩家运动辅助)。

## 实时字幕（`CaptionTrack` 与 `CaptionsView`）

通过 `CaptionTrack` 推送定时对话、带方向指示的音效、音乐提示或重要告警，在 `game.Loop` 中推进计时，并用 `CaptionsView` 作为原生 NSGo 视图叠加显示：

```go
captions := a11y.NewCaptionTrack(cx)

// 玩家右侧传来爆炸声（direction 范围 [-1, 1]）：
if assist.SFXCaptionsEnabled() {
	captions.ShowSFXAt("爆炸声", 0.8, 2500*time.Millisecond)
}
captions.ShowDialogue("向导", "小心前方的吊桥。", 3*time.Second)

// 在 game.Loop.Update 中：
captions.Update(dt)

// 在根 Stack 视图中叠加：
a11y.CaptionsView(cx, captions, a11y.CaptionStyle{Assist: assist})
```

`Caption.Format()` 会自动格式化说话人（`"向导: ..."`）、音效括号（`"[爆炸声]"`）、方向性立体声标记（左侧 `"[<] [爆炸声]"`、右侧 `"[爆炸声] [>]"`，在 `|Direction| >= 0.25` 时显示）、重要告警前缀（`"! ..."`）与音乐提示（`"♪ ..."`）。可用 `Dismiss(id)` 或 `Clear()` 提前清除条目。

可通过 `CaptionStyle.RegionLabel`（默认 `"Captions"`）、`CaptionStyle.ImportantPrefix`（默认 `"! "`）与 `CaptionStyle.MusicPrefix`（默认 `"♪ "`）自定义实时区域的无障碍名称与前缀，或用 `CaptionStyleFromCatalog` / `CaptionStyleFromLocalizer` 从 `l10n.Catalog` / `l10n.Localizer` 填充。

## 单声道音频与立体声平衡

面向单耳听力玩家，[`game/sound`](sound.md#单声道音频与左右平衡)、`game/save` 与 `game/gameui` 联合提供单声道声像居中与左右平衡设置：

- **`save.AudioSettings`**：`Mono`（`*bool`，默认为 `nil` 以跟随系统单声道开关）与 `Balance`（`float64`，范围 `[-1, 1]`，默认 `0` 居中）随玩家设置持久化，并由 `save.Apply` 自动应用到 `*sound.Mixer`（`SettingsTargets.Sound`）。
- **`sound.Mixer`**：`SetMono(bool)` / `FollowSystemMono()` 与 `SetBalance(float32)` 在开启单声道时将每次发声的声像设为 `0`（同时保留距离、后方头影与定向声源锥衰减），关闭单声道时按 `Balance` 偏移立体声声像并截断到 `[-1, 1]`。`Listener2D.Pan` 与 `Listener3D.Pan` 仍返回真实空间方向，因此传给 `CaptionTrack.ShowSFXAt` 的方向性字幕在单声道下依然保留方向线索。
- **`gameui.SettingsMenu`**：音频标签页包含直接绑定到 `save.AudioSettings` 的 **Mono Audio**（`System Default` / `On` / `Off`）与 **Balance** 两行控件。
- **NSGo v0.3.4 当前限制**：在 NSGo 支持将最终输出混音为单声道（`nsgo-dev/nsgo#2676`）之前，立体声音频资源（如立体声音乐或环境音）仍保留各自声道；系统单声道开关的自动跟随将在 NSGo 暴露 `Env.MonoAudio`（`nsgo-dev/nsgo#2677`）后生效。

## 色盲友好调色板与 CVD 模拟

`PaletteFor(mode)` 返回基于 Okabe-Ito / Wong 方案的语义调色板 `Palette`（含 `Player`、`Ally`、`Enemy`、`Hazard`、`Pickup`、`Neutral`、`Background`、`Foreground`、`Highlight`、`Accent`）。可在测试或运行时主题中使用 `Simulate`、`ContrastRatio` 与 `EnsureContrast`：

```go
pal := assist.Palette()
simEnemy := a11y.Simulate(pal.Enemy, a11y.VisionDeuteranopia)
ratio := a11y.ContrastRatio(pal.Foreground, pal.Background)
readable := a11y.EnsureContrast(accentColor, pal.Background, 4.5)
_, _, _ = simEnemy, ratio, readable
```

## 屏幕阅读器菜单（`AccessibleMenu`）

用 `AccessibleMenu` 渲染暂停、设置与辅助选项菜单，内置原生无障碍角色（`RoleMenu`、`RoleMenuItem`、`RoleMenuItemCheckbox`）、完整键盘导航（`Up`/`Down`/`Home`/`End`/`Return`/`Space`/`Escape`）及 `cx.Announce` 实时朗读播报：

```go
a11y.AccessibleMenu(cx, a11y.MenuProps{
	Label:   "辅助选项",
	Assist:  assist,
	OnClose: closeMenu,
	Items: []a11y.MenuItem{
		{
			ID:       "reduce-motion",
			Label:    "减弱动态效果",
			Checked:  assist.ReduceMotion,
			OnSelect: func() { _ = assist.SetReduceMotion(!assist.ReduceMotion()) },
		},
		{
			ID:       "game-speed",
			Label:    "游戏速度",
			Value:    func() string { return fmt.Sprintf("%d%%", int(assist.GameSpeed()*100)) },
			OnSelect: cycleGameSpeed,
		},
	},
})
```

当焦点移动到原生上报 `Checked` 状态的角色（`RoleMenuItemCheckbox`、`RoleMenuItemRadio`、`RoleCheckbox`、`RoleSwitch`、`RoleRadio`）时，`AccessibleMenu` 交由平台自身朗读勾选状态而不再重复播报；切换开关与打开菜单时仍会播报完整状态。

## 本地化（`MenuText` 与 `l10n`）

`pkg/a11y` 内嵌英文（`en`）与简体中文（`zh`）`l10n` YAML 字符串表。可直接调用 `DefaultCatalog()`，或在加载游戏自定义翻译前调用 `LoadDefaultCatalog(cat)` 将默认词条合并进游戏的目录。

通过 `MenuProps.Text` 传入 `MenuText`（未填写的字段自动回退到 `DefaultMenuText()`），或使用 `MenuTextFromCatalog` / `MenuTextFromLocalizer` 从目录构建：

```go
cat := a11y.DefaultCatalog()
loc := l10n.NewLocalizer(cx, cat)
loc.SetLocale("zh-Hans")

capStyle := a11y.CaptionStyleFromLocalizer(loc)
capStyle.Assist = assist

a11y.AccessibleMenu(cx, a11y.MenuProps{
	Label: "辅助选项",
	Text:  a11y.MenuTextFromLocalizer(loc),
	Items: items,
})
```
